# Лабораторна робота №5 — Робота з файлами

**Студент:** Шоробура Костянтин  
**Група:** ІК-52

## Тема проєкту
Розроблення інформаційної системи для статистичного аналізу футбольних турнірів із використанням технології об'єктно-орієнтованого програмування.

## Завдання
Варіант 16. Сформувати файл із результатами чемпіонату з футболу для 16 команд. За перемогу нараховується 2 очки, за нічию — 1, за поразку — 0. Програма записує масив структур у файл `championship.dat`, читає його, формує турнірну таблицю та визначає три команди-призери і кількість їхніх перемог.

## Файли
- `main.cpp` — програма C++17;
- `sample_input.txt` — контрольні вхідні дані.

## Компіляція
```bash
g++ -std=c++17 main.cpp -o lab5
```

## Запуск із контрольними даними
```bash
./lab5 < sample_input.txt
```
